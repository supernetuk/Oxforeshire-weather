# Oxforeshire-weather

Oxfordshire weather project by Supernet UK Limited.

## Getting started

```bash
git clone https://github.com/supernetuk/Oxforeshire-weather
cd Oxforeshire-weather
claude        # open Claude Code in this folder
```

Add what this project does, how to run it and how to deploy it as it grows.

## Secrets

Never commit API keys or passwords. Put them in `.env` (ignored by git) and list the variable names in `.env.example`. For Cloudflare Workers, use `wrangler secret put`.
